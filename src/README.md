# Passo a Passo de Execução do Agente ORIENTA

```bash
 1. Instalar Ollama (ollama.com)
 2. Baixar um modelo leve(aqui utilizei o gemma:2b
 3. Testar se funciona
 ollama run gemma:2b "Olá"
```

## Código Completo
Todo Código Completo está no arquivo `orienta.py`. 

## Como executar
```bash
1. Instalar dependências
2. pip install -r requirements.txt
```
## Garantir que o ollama está funcionando
ollama serve

## Executar a aplicação
streamlit run ./src/orienta.py
